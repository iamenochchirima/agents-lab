# Anesu implementation plans

This directory contains plans for Anesu, the Computer Native agent. Its plans cover
the standalone agent runtime, terminal interface, tools, computer interaction,
workspace and filesystem capabilities, memory, security, persistence, and local
operational behaviour.

Anesu is kept separate from the execution platforms and from Studio. The follow-on
order is recorded in the [Anesu follow-on queue](anesu-follow-on-queue.md).
