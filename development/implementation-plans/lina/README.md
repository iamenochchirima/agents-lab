# Lina implementation plans

This directory contains plans for Lina, the Computer Native agent. Its plans cover
the standalone agent runtime, terminal interface, tools, computer interaction,
workspace and filesystem capabilities, memory, security, persistence, and local
operational behaviour.

Lina is kept separate from the execution platforms and from Studio. The follow-on
order is recorded in the [Lina follow-on queue](lina-follow-on-queue.md).
