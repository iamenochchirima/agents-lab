# Development workspace

This directory holds local-development material that helps maintainers understand and
develop Agent Harness Lab but is not part of a published scenario, experiment, or run
result.

Its contents must make their temporary or developer-facing purpose clear. Do not use
this directory as an unreviewed alternative home for production implementation code.

- [`playground/`](playground/): small, observable walkthroughs of real implementation
  slices, maintained primarily as a learning and inspection environment.
