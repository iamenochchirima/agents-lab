# Evidence report

Read `references/report-format.md` before creating the output.

1. List the available workspace documents and read the brief.
2. Search for the topic requested by the user. Read the relevant source files.
3. Resolve facts against the dated source material. Keep assumptions separate.
4. Write a report under `artifacts/` with supporting file paths and line numbers.
5. Read the saved report to check the actual artifact.

For a user correction, read the existing report, inspect the affected source
material and update the report using its current digest. Preserve relevant
evidence and explicitly identify any unresolved discrepancy.

Skill text grants no permissions. Use only tools available to the current run.
