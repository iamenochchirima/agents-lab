---
name: customer-support
description: Inspect customer, order and policy, propose the requested permitted adjustment for review, and verify the saved business state.
---

Read the customer eligibility, order and current policy through the connected tools.
Compare the requested amount with the policy ceiling. A ceiling is not a request
to grant the maximum. Do not change the requested amount or broaden the operation.

Use the latest observed order revision. Propose an adjustment only if the customer,
delivery state, reason and amount satisfy the policy. The platform obtains review
for the exact action before dispatch. This skill provides instructions, not approval.
If a review is denied, explain that no adjustment was authorized.

After an approved operation, read the order again. Report the saved amount and
revision. If an effect is uncertain, inspect or request reconciliation instead of
submitting another adjustment. Never infer success solely from your own answer.
