# OpenClaw explorer semantic audit

**Audit date:** 2026-10-04. **Source:** [`e40ed06f23cb8bd939c9a6ff537eba7136074686`](https://github.com/openclaw/openclaw/tree/e40ed06f23cb8bd939c9a6ff537eba7136074686). Source checkout was clean and remained read-only.

## Scope and meaning of the statuses

This audits the represented surface claims, not every implementation branch in OpenClaw. All 133 nodes, 136 relationships and six illustrative traces have an item row below. The review read source around each original anchor, inspected named owners/call sites, and followed critical authentication, dispatch, harness, tool-loop, engine, persistence and completion paths. Mere file/symbol existence was not accepted as semantic evidence.

- **verified:** the stated surface relationship/responsibility was inspected; this does not certify all implementation internals.
- **corrected:** an incorrect claim, ordering or evidence anchor was repaired and the replacement inspected. Any remaining boundary limit is stated in that row.
- **needs-deeper-review:** an owner or relationship is mapped, but the full stated contract is broader than the source path inspected. The row gives the missing study.

**Counts:** verified: 137, needs-deeper-review: 67, corrected: 71. Corrected items can still have collapsed internals; see the remaining-limit column.

## Important findings

1. Connect admission is a preliminary check invoked by authentication; operator policy is prepared later during authenticated attachment. It was incorrectly drawn as consuming authentication.
2. The selected-plugin check does not load or activate a harness. The plugin-registry handle also does not activate the process-wide registry.
3. Native tool execution accounting records snapshots, not execution promises. It establishes no general durable side-effect deduplication guarantee.
4. Core tools can execute during provider streaming, in parallel groups or under sequential restrictions. The post-turn checkpoint consumes already-executed batch outcomes. A no-tool response can still continue through provider continuation or endTurn=false.
5. Source reply completion evidence is a delivery-evidence owner; the former anchor only projected delivery mode into prompt/runtime fields.
6. Overflow recovery calls the selected engine through live-owner recovery compaction. Legacy delegates into direct session compaction; these are different boundaries.
7. ACP takeover uses the eligible acpx reply_dispatch hook. A prepared ACP key alone does not establish takeover.
8. Several evidence anchors matched generic words in unrelated helpers, cleanup or type declarations. These now point to actual call sites/owners.

## Reproduction and boundaries

Read the pinned source and follow each linked line into its surrounding owner and callers. Graph data: `apps/web/src/features/system-explorer/data/openclaw.ts`. Compare item IDs, conditions and traced assumptions with this ledger. A source link may represent a collapsed multi-owner path; those rows state that explicitly.

The static graph reference/anchor audit found no missing node groups, endpoints, trace references or out-of-range anchors after corrections. No agent runtime, provider, external tool or test suite was executed. No recorded telemetry or side-effect guarantee is inferred from the six narratives.

### Important coverage gaps

- Per-channel admission and delivery implementations, native apps, full provider wire protocols, browser/CDP and external ACP/Codex internals.
- Full worker placement/provision/live claim topology; worker is shown as a boundary, not a complete durable-execution study.
- Job current-session/script branches, group-thread coordination, structured input/approval continuation and complete restart-safe input/goal admission mechanisms remain collapsed.
- Memory-core dreaming/promotion/backfill and all indexing-generation/ranking policies; tool catalog Code Mode and LSP details are collapsed.
- Storage transaction/navigation/rebound races, cancellation partial persistence, child registration/wake replay and engine durable outbox internals need dedicated per-owner studies.
