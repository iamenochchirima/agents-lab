# Context Lab: harness lifecycle studies

Follow context through real source code before choosing experiment boundaries.
Each study pins its source revision, diagrams the lifecycle and separates defaults,
optional mechanisms and limits of the audit.

- [Hermes context lifecycle](hermes.md): instructions → turn context → request → tool feedback → compaction → persistence and resume.

The [Lina Context comparison](../lina/context-research.md) adds pinned studies
of Hermes/OpenClaw and Pi/Waku, proposed design nodes and experiments. Detailed
standalone lifecycle walkthroughs for OpenClaw, Waku and Pi remain future work.

These are research documents. They do not change Studio contracts or establish benchmark results.
