# Start here

Agent Harness Lab is an experimental engineering project for comparing agent
harness architectures under comparable scenarios and failures.

Start with the [project vocabulary](concepts/vocabulary.md), then read the
[architecture overview](architecture/system-overview.md). If you are working in
the repository, use [local development](guides/local-development.md).

The **Initial development** section contains working maps and reference-harness
study notes. They help us build the project, but they are not the public product
documentation structure.
