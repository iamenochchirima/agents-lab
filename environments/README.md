# Environments

An environment defines what a harness can observe and interact with while it runs.

It includes capabilities and restrictions such as files, processes, shell access, network access, workspace lifetime, permissions, resource limits, and isolation. Environments are independent of the platform that controls the agent's execution.

Harness variants declare compatibility with environment variants. The environment
remains independent even when the UI displays that relationship beneath a platform.

Only add an environment when a scenario or experiment gives it a concrete purpose.
